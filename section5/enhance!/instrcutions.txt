# Instructions for exercise 1, problem set 5: Enhance!

Download this image file and find the flag.

https://artifacts.picoctf.net/c/100/drawing.flag.svg

There is no hint for this exercise, after downloading the image with wget, we
need to check the properties and information of the image. The first step
is intalling exiftool using, sudo apt install exiftool, after that execute the
code with the image as an argument, it will provide you bunch of information
about the image, then run the strings command with the picture downloaded
as an argument again, each line of information will provide some information
pof the flag.
