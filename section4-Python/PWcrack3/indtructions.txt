# Instructions

Can you crack the password to get the flag?

Download the password checker here and you'll need the encrypted flag
and the hash in the same directory too.

There are 7 potential passwords with 1 being correct. You can find these by examining the password checker script.

2. To exit bvi type :q and press enter
3. The str_xor function does not need to be reverse engineered for this challenge

First use wget to download all the files give using the command prompt
then inspect all the files using your favorite text editor. After cheking the code on
the file level3.py go to the bottom and there are 7 different passwords
execute the python code with using python3 *file.py* then copy and paste the each
